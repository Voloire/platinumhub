Le stesse sette checklist come file HTML singoli, bilingui (pulsanti
ITA / ENG in alto a destra).

Non serve Python: doppio click e si aprono nel browser. Ma NON salvano
da soli - un file HTML da solo non ha un database. Prima di chiudere
premi "Copia codice progressi" e tieni il codice in un file di testo
tuo, poi "Carica codice" la volta dopo.

Usali per condividere (Drive, telefono, un amico) o come scorta.
Per giocare usa l'hub (run.bat): quello salva da solo.

The same seven checklists as single bilingual HTML files (ITA / ENG
buttons, top right). No Python needed - double-click and they open.
They do NOT save by themselves: hit "Copy progress code" before closing
and keep the code in a text file, then "Load code" next time.
For playing, use the hub (run.bat) - it saves automatically.
